Integrity and packaging release from the Claude v1.1.2 review. **No data change**: every SQLite table except `meta`, and every chapter JSON apart from `dataset_version`, is identical to v1.1.2.

- Sources: `.gitattributes` keeps `sources/**` byte for byte on Windows. The build checks every source against `sources/SHA256SUMS` first. The signed triage CSV is LF and pinned.
- Triage policy comes from an explicit `decision` column (override / uncertain / optional / divide / join / compare / leave). An unknown value stops the build.
- Pins come from `sources/PINS.txt` only. `built_at` comes from `SOURCE_DATE_EPOCH` or the commit date, so a build is reproducible byte for byte.
- SQLite indexes on `accent(word_id)`, `word_alt(host_id)` and `unit(ref)`.
- `LICENSE` (MIT) for the code. `LICENSE-DATA.md` for the data. README, LICENSE-DATA.md and LICENSE are inside both tars.
- Built from the tagged commit with `SOURCE_DATE_EPOCH`, checked (`check_dist`, full-corpus canon.ts parity) and packaged by `scripts/package.sh`, with `SHA256SUMS`. The tag workflow is in `docs/ci/` waiting to be installed (the push token has no `workflow` scope).
